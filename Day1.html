So you recently started to know about the basics of coding.

Coding seekhne ke liye sabse best aur easy language SQL hota hai. SQL ka full form Structured Query Language hai.

SQL ka use database ke saath kaam karne ke liye kiya jata hai. SQL mein hum simple English keywords ka use karke database ke saath different operations perform kar sakte hain.

Some Common SQL Commands

CREATE

CREATE ka use database mein objects, jaise tables, create karne ke liye hota hai.

ALTER

ALTER ka use existing database objects ko modify karne ke liye hota hai.

INSERT

INSERT ka use table ke andar data add karne ke liye hota hai.

SELECT

SELECT ka use database se data retrieve ya dekhne ke liye hota hai.

UPDATE

UPDATE ka use existing data ko modify karne ke liye hota hai.

DELETE

DELETE ka use table se data remove karne ke liye hota hai.

What is a Database Object?

Shayad aapko "object" ka matlab samajh mein nahi aaya. Basically, database object us cheez ko bolte hain jisme database ka data structured way mein manage kiya jata hai.

Jaise aap maan lo ki ek library hai aur usmein books idhar-udhar rakhi hui hain. Agar aapko Class 11 ki koi book leni ho, to aapko poori library dhundhni padegi.

Lekin agar saari books class ke hisaab se apni-apni jagah par rakhi hui hain, to unhe dhundhna bahut aasaan ho jata hai.

Waise hi, agar public ke dwara diya hua data, jaise naam, ID, roll number aur phone number, ek structured format mein rakha ho, to kisi particular person ka data nikalna aasaan hota hai.

Role of DBMS

Isi kaam mein DBMS (Database Management System) help karta hai.

DBMS ki help se hum databases aur tables create karte hain aur unmein data ko store, manage aur retrieve karte hain.

MySQL ek popular relational database management system (RDBMS) hai jo SQL ka use karke databases ke saath kaam karta hai.
