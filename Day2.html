Sabse pehle table banate h

Table banane ke liye hum CREATE TABLE command ka use karte hain. Table ek tarah ka structure hota hai jisme hum apna data store karte hain.

CREATE TABLE table_name (column1 VARCHAR(50), column2 INTEGER, column3 VARCHAR(15));

Isme jo keywords capital letters me diye gaye hain, unhe as it is likhna hota hai.
table_name ki jagah aap apni table ka koi bhi naam de sakte ho, jaise Student.
Isi tarah column1, column2 aur column3 ki jagah aap apne data ke according column names de sakte ho, jaise name, roll_no aur phone.

Example:

CREATE TABLE Student (name VARCHAR(50), roll_no INTEGER, phone VARCHAR(15));

Is command se Student naam ki ek table create ho jayegi. Is table me hum student ka naam, roll number aur phone number store kar sakte hain.

Important: Table create karte waqt har column ka ek data type dena zaroori hota hai. VARCHAR ka use text ya characters ke liye aur INTEGER ka use whole numbers ke liye kiya jata hai.

Ab agar aap apni table ka structure dekhna chahte ho, to ye command likho:

DESC Student;

Is command se aapko Student table ka structure dikh jayega, jisme table ke andar kaun-kaun se columns hain aur unka data type kya hai, ye sab information milegi.

Ab table me data dalte hai.

Table create karne ke baad uske andar data insert karna hota hai. Data insert karne ke liye hum INSERT INTO command ka use karte hain.

INSERT INTO table_name VALUES (Value1, Value2, Value3);

Yaha table_name ki jagah apni table ka naam likhna hota hai aur columns ke naam ke according values deni hoti hai.
Table ka structure bnate time jo column pehle likha tha uska value pehle dalna,
jaise create table krte time pehle name fir roll fir admn likha h to usi hisab se value bhi dalna hoga.

Example:

INSERT INTO Student VALUES ('Aamir', 1, '9876543210');

Is command se Student table me ek student ka data insert ho jayega.

Agar aapko ek aur student ka data insert karna hai, to aap isi command ka dobara use kar sakte ho.

INSERT INTO Student VALUES ('Zeenat', 2, '9876543211');

Isi tarah aap jitne students ka data store karna chahte ho, utni baar INSERT INTO command ka use kar sakte ho.

Important: Text ya character values ko generally single quotes ' ' ke andar likha jata hai, jaise 'Aamir'. Lekin number values ko normally quotes ke bina likha jata hai, jaise 1 ya 2.

Ab jo apne data dala h wo apko kaise dikhega ?

Table me data insert karne ke baad agar aap us data ko dekhna chahte ho, to hum us data ko SELECT command ki help se fetch karte hain.

Agar aap table ka poora data dekhna chahte ho, to ye syntax use karo:

SELECT * FROM table_name;

Example:

SELECT * FROM Student;

Is command se Student table ke andar jitna bhi data stored hai, wo sab aapko dikh jayega.

Lekin maan lo ki aapko poora data nahi dekhna hai aur sirf students ke naam dekhne hain, to aap sirf required column ko select kar sakte ho.

SELECT name FROM Student;

Is command se sirf name column ka data show hoga.

Isi tarah agar aapko naam aur roll number dono dekhne hain, to aap likh sakte ho:

SELECT name, roll_no FROM Student;

Pata hai? Aap kisi condition ke according bhi data fetch kar sakte ho. Jaise agar aapko sirf us student ki information chahiye jiska roll number 1 hai, to aap WHERE clause ka use kar sakte ho. Ye sab hum aage SQL me detail me seekhenge.

Abhi ke liye aapko itna samajhna hai ki CREATE TABLE se table banti hai, INSERT INTO se table me data add hota hai, aur SELECT se table ke andar ka data fetch ya display kiya jata hai.
